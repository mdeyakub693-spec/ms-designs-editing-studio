MS DESIGNS N EDITING STUDIO — WEBSITE STARTER

OPEN IT
1. Extract the ZIP file.
2. Open the ms_designs_website folder.
3. Double-click index.html to open the website in Chrome.

CUSTOMIZE IT
- The portfolio cards are sample concepts. Replace them with your real designs before sharing as a finished portfolio.
- In index.html, search for your-email@example.com and replace it with your email address.
- Edit the text in index.html using Notepad or another text editor.
- “Add your designs” previews selected images in the current browser session only; it does not permanently add them to the website files.

PUBLISH IT
This is a static website. You can publish it free with GitHub Pages or Netlify by uploading the extracted folder. You will need to sign in to the hosting service.
